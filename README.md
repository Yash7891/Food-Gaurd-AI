# FoodGuard AI

## 📖 Project Overview
FoodGuard AI is an end‑to‑end food‑safety verification system focused on the Indian market. It combines computer‑vision models (MobileNetV2 for spoilage detection, CLIP for out‑of‑food filtering, EasyOCR for nutrition label extraction) with domain‑specific rules from the FSSAI guidelines to provide a clear safety verdict for raw produce and packaged foods.

---

```mermaid
    A[User uploads image] --> B{Image type?}

    D --> F[Nutrition extraction]
    E & F --> G[Guardrail checks]
    G --> H[Health score & verdict]
    H --> I[Web UI display]
```

Food‑safety detection for Indian consumers. Upload a photo and get a clear verdict:
**SAFE / CAUTION / UNSAFE**, or **REJECTED / MISMATCH** when the image is unusable.

## 📋 Key Features
- **Raw produce** – fine‑tuned MobileNetV2 detects spoilage; Grad‑CAM visualises the decision.
- **Packaged food** – EasyOCR reads nutrition panels; FSSAI HFSS limits are applied.
- **Guardrails** – automatic checks for “is this food?”, correct category, and product identity.
- **Offline fallback** – when the internet is unavailable the app uses cached models and synthetic sample data. *(see commit `b0e99e7`)*.
- **Extensible pipelines** – add new datasets or models with minimal code changes.
- **Health score & review** – 0‑100 scoring with star display and detailed explanation.

## 📦 Installation

```powershell
# 1️⃣ Clone the repo
git clone https://github.com/Yash7891/Food-Gaurd-AI.git
cd Food-Gaurd-AI

# 2️⃣ Create and activate a virtual environment
python -m venv .venv
.venv\Scripts\activate    # PowerShell
# .venv/bin/activate      # Bash

# 3️⃣ Install PyTorch (pick the appropriate line)
#    • NVIDIA GPU (RTX 50‑series → cu128)
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
#    • CPU‑only (no NVIDIA GPU)
# pip install torch torchvision

# 4️⃣ Install the remaining dependencies
pip install -r requirements.txt
```

## ▶️ Running the app

```powershell
python app.py        # opens http://127.0.0.1:5000
```

Navigate to the URL in a browser, select a category, upload a photo, and press **Check this food**.

## 📂 Dataset & Offline fallback

The first run downloads the CLIP model (~600 MB) and EasyOCR weights (~100 MB).
If you are offline, the repo automatically falls back to:

- Cached CLIP/EasyOCR weights (included in `models/` after the first run).
- Synthetic sample data generated by `scripts/make_synthetic_labels.py`.

You can manually trigger the fallback:

```powershell
python scripts/download_datasets.py --offline
```

## 📊 Sample data generation

```powershell
python scripts/make_synthetic_labels.py --num 10   # creates 10 synthetic images in `data/`
```
